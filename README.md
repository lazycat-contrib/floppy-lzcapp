# Floppy - 懒猫云应用

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![LazyCat Cloud](https://img.shields.io/badge/LazyCat-Cloud-blue)](https://lazycat.cloud)

Self-hosted all-in-one media tracker and Trakt alternative for movies, TV, anime, books, games, music, and podcasts.

## 功能特性

- 🎬 **影视追踪**: 记录和追踪你看过的电影、电视剧
- 📚 **书籍管理**: 管理你的阅读清单和阅读进度
- 🎮 **游戏记录**: 追踪你的游戏游玩历史
- 🎵 **音乐收藏**: 整理你的音乐收听记录
- 🎙️ **播客订阅**: 订阅和管理播客节目
- 🔒 **自托管**: 完全掌控你的数据

## 安装说明

通过懒猫应用商店安装，搜索 "Floppy" 即可。

## 配置参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 时区 | 应用时区设置 | Asia/Shanghai |
| 管理界面 | 是否启用管理界面 | False |
